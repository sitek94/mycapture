# Contributing

myCapture is a personal project, built for my own Mac and shared as-is.

- **Pull requests are not accepted.** They are closed automatically. This isn't about the quality of your change: I keep the feature set small on purpose and don't want to maintain code I didn't write. Fork the repo and make it yours — the MIT license allows anything.
- **Bug reports are welcome** as GitHub issues, using the bug template: what you did, what happened, macOS version. Feature requests will be closed.
- **No support.** I may fix bugs that affect me; there's no promise of a reply or a timeline.
